# Python Learning Path: Week 0 to Week 10

This curriculum is for learners who are new to programming. Each week builds on earlier ideas and should contain:

1. A `lesson.md` that teaches the week's concepts before students attempt the assignments.
2. A `problem_set.ipynb` with problems to solve at the end of the week. Student notebooks should contain prompts, examples, and starter cells—not completed solutions.

The existing cumulative-distance notebook is an additional set of worked examples, not a replacement for the weekly problem set.

## Weekly progression

| Week | Main topic | Concepts and outcomes | End-of-week problem set ideas |
|---|---|---|---|
| **0** | Environment and Python fundamentals | Install and run Python; use an editor and notebooks; `print`, comments, variables, basic types, input and conversion, arithmetic, assignment and augmented assignment, comparisons, logical operators, conditionals, loops, functions, and reading errors. | Personalized greeting; age or unit calculator; even/odd and rule-based decision functions; loop-based count and total; simple guessing task. |
| **1** | Collections | Lists, tuples, dictionaries, and sets; indexing and slicing; mutability; adding and looking up data; membership; iteration; choosing a collection. | Filter and summarize lists; work with coordinate tuples; look up and count dictionary entries; remove duplicates and compare sets; update a copied inventory. |
| **2** | Strings and text | Strings as sequences; indexing and slicing; `lower`, `strip`, `split`, `join`, and `replace`; f-strings; simple text validation. | Normalize a name; count words or characters; detect a palindrome; format a receipt; extract initials or analyze a sentence. |
| **3** | Control flow and iteration | `for` and `while` loops in depth; `range`; nested loops; accumulators; `break` and `continue`; common loop patterns. | Number guessing with repeated attempts; multiplication table; find minimum/maximum; pattern printing; process repeated user input. |
| **4** | Functions and decomposition | Parameters, return values, local variables, scope, default arguments, decomposition, docstrings, and writing small test cases with `assert`. | Split a calculator into functions; validate inputs; convert units; write and test reusable helper functions; combine helpers into a small program. |
| **5** | Problem-solving patterns | Linear search; counting and grouping; min/max; sorting with built-ins and `key`; simple algorithm efficiency intuition; choosing a clear approach before optimizing. | Find an item and its position; frequency analysis; rank scores; find repeated values; solve a cumulative-distance challenge and explain its approach. |
| **6** | Files, exceptions, and debugging | Read and write text files; work with paths; use `with`; understand common exceptions; handle expected invalid input; inspect tracebacks and debug systematically. | Read a text file and summarize it; save and reload notes; validate numeric input; report missing-file errors clearly; process a small CSV with the standard library. |
| **7** | Modules and project organization | Import modules; use selected standard-library tools; create reusable modules; use a virtual environment and install a package; organize a small multi-file project. | Build a date or random-number utility; split a program into modules; make a command-line quiz; document how to run the project. |
| **8** | Object-oriented programming | Classes and objects; `__init__`; instance attributes and methods; represent related state; distinguish when a class helps versus a simple function or dictionary. | Create a `Book` or `BankAccount` class; add methods and invariants; model a small collection of objects; test object behavior. |
| **9** | Structured data and APIs | Read and write JSON; understand CSV and JSON data shapes; make a basic HTTP request using a suitable library; inspect responses and handle common network/API errors. | Load a JSON settings file; summarize CSV records; fetch public API data; extract and present selected fields; handle unavailable or unexpected responses. |
| **10** | Capstone and review | Plan a small program; break requirements into functions or modules; choose data structures; test normal and edge cases; document and demonstrate the result. | Complete a student-chosen project such as a quiz game, reading tracker, study planner, or simple inventory tool, with tests and a short usage guide. |

## Suggested course habits

- Start each week by reading the lesson and running its examples.
- Attempt the problem set only after the concepts have been introduced.
- Encourage students to write down expected input and output before coding.
- Test edge cases such as empty input, one item, repeated values, and invalid input where relevant.
- Prefer readable, correct solutions before introducing performance improvements.
- Keep answer keys separate from student-facing problem notebooks.
- Reserve time each week for students to explain their approach and reflect on what they learned.
